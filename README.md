# 🏬 Dynamic Out-of-Stock Forecast & Revenue Loss Estimator

**Business Problem:**  
Retailers like Amazon, Walmart, and Target lose millions due to *stockouts* (when items go unavailable).  
This project predicts **which SKUs** are at risk of stockout in the next 7 days and estimates **potential revenue loss**.
